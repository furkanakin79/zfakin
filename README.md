# 🦄 Ders Yıldızı & Matematik Sihirbazı Portali ✨

Kızınız için özel olarak tasarlanan iki harika proje tek bir çatı altında birleştirildi!

## 🌟 Portaldaki Modüller

### 1. 📅 Çalışma Planı (Kuromi Summer Study Planner)
- **Ders & Görev Takibi:** Pazartesi - Pazar günleri, dinamik ders programı ve görev tamamlama listesi.
- **Seviye, XP & Seri:** Tamamlanan görevlerle seviye atlama, XP barı ve günlük seri sayacı.
- **Saat 20:00 Hatırlatıcı Alarmı:** Günün görevleri bitmediğinde motive edici çan uyarısı.
- **Raporlar & Analizler:** Günlük, haftalık, aylık ve özel tarih filtreli Chart.js grafikleri (Ders dağılımı, Soru sayıları, Gitar çalışmaları).
- **Kitaplığım 📚:** Okunan kitapları ekleme ve listeleme.
- **Yıldız Rozetleri 🏆:** Başarılara göre açılan sevimli rozet galerisi.
- **Veri Yedekleme / Yükleme:** Tek tıkla JSON yedeği alma ve geri yükleme.

### 2. 🦄 4 İşlem Sihirbazı (Matematik Oyunu)
- **4 İşlem & Karışık:** Toplama, Çıkarma, Çarpma, Bölme (Kalanlı ve kalansız) ve Karışık mod.
- **Basamak Seçimi:** 1'den 5'e kadar basamak seçebilme (örn: 3'e 2 basamak `255 + 25` vb.).
- **Soru Düzeni:** Klasik (Alt Alta / Bölme Çizgili Tablo) ve Düz (Yan Yana) modları.
- **Geri Sayım Sayacı:** 10 saniye (ayarlanabilir veya süresiz) canlı renkli bar.
- **Dokunmatik Numpad & Klavye:** Tablette ekranı kapatmayan büyük butonlar ve klavye desteği.
- **Takvim & Karne:** Günlük/haftalık çözülen soru, doğru-yanlış, başarı oranı ve geçmiş/gelecek takvim karnesi.

## 🚀 GitHub Pages ile Tablete Kurulum (1 Dakika)

1. [github.com](https://github.com) üzerinde yeni bir **Public** repo oluşturun (örn: `ders-yildizi`).
2. Bu klasördeki (`matematik-sihirbazi`) dosyaları repoya yükleyin:
   ```bash
   git init
   git add .
   git commit -m "feat: Ders Yildizi ve Matematik Sihirbazi Portali"
   git branch -M main
   git remote add origin https://github.com/KULLANICI_ADINIZ/ders-yildizi.git
   git push -u origin main
   ```
3. GitHub reponuzda **Settings -> Pages** menüsüne gidin.
4. **Branch** olarak `main` ve `/ (root)` seçip **Save** butonuna basın.
5. Birkaç saniye içinde linkiniz hazır: `https://KULLANICI_ADINIZ.github.io/ders-yildizi/`
6. Tabletinizden (iPad Safari veya Android Chrome) açıp **"Ana Ekrana Ekle"** dediğinizde kızınız tek uygulamadan hem çalışma planını hem de 4 işlem oyununu tam ekran oynayabilir!
